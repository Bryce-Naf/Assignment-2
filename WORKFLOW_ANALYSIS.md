Whenever code is pushed to the main branch, the workflow will run.

The four main steps this workflow performs are:
1. Get the code from the repository
2. Validate HTML files
3. Check for broken links
4. Upload the built site

The checkout code step pulls the code from the repository so that it can confirm that the code functions properly.

The environment configuration makes sure that the environment that the code is going into will function properly and not have issues.
